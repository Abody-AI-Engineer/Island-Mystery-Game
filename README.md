# 🏝️ The Island Mystery Game
Welcome to the Island! A logic-driven adventure game where every choice determines your fate.

## 🚀 Overview
This project is a text-based game designed to demonstrate advanced Python fundamentals, specifically focusing on complex decision-making trees and user input validation.

## 🧠 Key Learning Outcomes
- **Nested Logic:** Implementing multiple levels of `if-elif-else` statements.
- **String Normalization:** Using `.upper()` and `.lower()` to ensure the game is case-insensitive (Robust Code).
- **User Experience (UX):** Providing feedback for invalid inputs to prevent program crashes.

## 🎮 How to Play
1. Run the script `syntax game.py`.
2. Choose your door (Red or Blue).
3. If you survive, choose a box (White, Green, or Black).
4. Find the treasure to win! 💰
